# Synchronous FIFO (Verilog)

## Overview

Parameterized synchronous FIFO design implemented in Verilog with basic verification.

## Features

* Configurable data width and depth
* Single clock operation
* Full and empty flag generation
* Pointer-based read/write logic

## Verification

Testbench verifies reset, read/write operations, and boundary conditions.

## Tools

Verilog, EDA Playground
